## Interpretation and corrections

Raw findings are observations. Keep every instance and link duplicates using root control plus response URL; HSTS is grouped by origin. A duplicate relationship overlaps a disposition and must not be added to disposition totals. Keep source, request phase, content type, body hash and original rule/title identity.

Private IPv4 detection requires four literal, bounded octets and RFC1918/loopback prefixes. SVG coordinates and invalid octets are negative controls. XML namespace identifiers do not request resources and are excluded from mixed-content candidates. Recognized fetch attributes remain candidates; navigation and dynamic references remain informational for execution-context review. This lexical scanner does not implement a browser.

Missing document policy on a fixed JS/icon response does not prove an HTML document failure. SVG can be an active document and requires embedding/script/document context. COOP/COEP/CORP are policy-dependent. Missing headers do not establish a demonstrated exploit; deployment needs an applicable threat model, route compatibility and a responsible publisher.
